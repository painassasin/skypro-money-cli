# SkyPro cli tool

## How to start

Set environment variables to `.bashrc`

```commandline
SKYPRO__EMAIL=ivan.ivanov@skyeng.ru
SKYPRO__PASSWORD=secret-password
```

Check money you are earned this month

```commandline
sky-cli
```

Another month or year

```commandline
sky-cli --month 3 --year 2026
```
